# Game Planner Portfolio – GitHub Pages

이 폴더는 GitHub Pages에 바로 배포할 수 있도록 정리된 웹 포트폴리오입니다.

## 구성
- `index.html`: HOME/PROFILE/GAMES/HISTORY/PORTFOLIO 웹사이트
- `assets/`: 사이트에서 사용하는 이미지 (원본 압축 이미지 품질 유지)
- `portfolio_documents/`: 사이트 PORTFOLIO 탭에서 링크한 원본 기획서 5개
- `.nojekyll`: 정적 사이트로 그대로 배포하기 위한 설정 파일

## 배포
1. GitHub Desktop으로 새 저장소를 생성합니다.
2. 이 폴더 안의 **모든 파일과 하위 폴더**를 저장소 안에 복사합니다.
3. GitHub Desktop에서 Commit to main → Publish repository를 선택합니다.
4. GitHub 저장소에서 Settings → Pages → Deploy from a branch → main / (root) → Save.
5. https://<GitHub계정명>.github.io/<저장소이름>/ 에서 확인합니다.

주의: 이 사이트는 공개됩니다. 게시 전 연락처 등 개인정보 공개 여부를 확인하세요.
문서 파일의 이름이나 폴더 위치를 바꾸면 HTML에 연결된 링크도 수정해야 합니다.
